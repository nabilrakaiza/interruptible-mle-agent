- **What did I ignore on purpose?** The details of the implementation. I'm not enough of an expert in this field to give the best judgement on them. This is noted as one of the project's limitations.
- **What would I have wanted to see?** A way to directly ask for one specific change and have the agent do it. The current system doesn't allow that: a redirect chooses only the node, and an injected card is a suggestion the agent can ignore.
